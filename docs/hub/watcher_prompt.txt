**LET OP — check `mergedAt`, niet alleen `state`.** Op 2026-11-04 stond `charlesvestal/fm1-base` PR #35 CLOSED terwijl hij nog geen merge had (`mergedAt: null`) — de `--state open`-filter ziet zo'n PR niet, dus hij leek "gewoon weg". Om dat te voorkomen, check elke PR op `mergedAt`:
`gh pr view <n> --repo <repo> --json number,state,mergedAt,mergeable,mergeStateStatus`
- `state == "OPEN"` én `mergedAt == null` → nog niet geland
- `state == "CLOSED"` én `mergedAt == null` → **gesloten zonder merge** → dit is een probleem: heropen 'm met `gh pr reopen <n> --repo <repo>` (werkt zonder extra rechten) en meld het.
- `mergedAt != null` → geland.
