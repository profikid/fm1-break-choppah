The letter to the Firmware Hub, at this release.

- The letter names this release and the package that goes with it, and carries only what the Hub's rules ask for: the name, the maker, the repository with the release, the identity, the licence, and that it was tested on a real FM-1 and you can leave it again.
- Everything else the Hub shows — what the firmware does, the picture, the manual, the browser version — comes from `fmhub.json` in the repository root, so it can be changed there without mailing again.

The firmware itself is unchanged: eight Amen-family breaks, sixteen slices each, a live generator, a four-slot FX chain and a DJ filter — and it installs on the newer units with the UC25HQ80 flash.
