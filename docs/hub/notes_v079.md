The letter to the Firmware Hub, ready to send, and the watcher's own rules.

- The letter points at this release and carries only what the Hub's rules ask for: the name, the maker, the repository with the release, the identity, the licence, and that it was tested on a real FM-1 and you can leave it again.
- The watch that checks the catalogues every twelve hours now reads the merged state of every pull request, so a pull request that is closed without a merge is caught instead of quietly disappearing.

No change to the firmware itself: eight Amen-family breaks, sixteen slices each, a live generator, a four-slot FX chain and a DJ filter — and it installs on the newer units with the UC25HQ80 flash.
