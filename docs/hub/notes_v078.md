Documentation: the promotion kit's own files, kept next to the letter to the Firmware Hub.

- `docs/hub/` holds the letter, the explanation and the upstream fix's pull request text, so the whole submission is in one place in the repository.
- `docs/promo/POSTS.md` holds the texts for the other catalogues and the communities.

No change to the firmware itself: eight Amen-family breaks, sixteen slices each, a live generator, a four-slot FX chain and a DJ filter — and it installs on the newer units with the UC25HQ80 flash.
